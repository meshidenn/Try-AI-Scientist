# exp-001: Baseline Workflow Smoke Test

This experiment checks whether the repository workflow can drive one complete
Kaggle iteration:

1. document dataset acquisition,
2. train a reproducible baseline,
3. write a valid submission file,
4. record metrics in Markdown and JSON,
5. audit artifacts before interpretation,
6. write a next-plan from stored evidence.

The goal is not leaderboard optimization. The goal is to discover which
artifact contracts are missing or awkward when a coding agent runs a real task.
