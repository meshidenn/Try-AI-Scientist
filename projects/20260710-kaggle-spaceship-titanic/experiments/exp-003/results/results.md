# Results

## Summary

Status: completed.

The larger local fixture run completed. It produced a second comparable
experiment under the same artifact contract as exp-002.

This result does not measure Kaggle leaderboard performance because the dataset
is synthetic.

## Setup

- Experiment: `exp-003`
- Data: synthetic fixture generated by `workspace/make_fixture_data.py`
- Train rows: 5000
- Test rows: 1200
- Model: `RandomForestClassifier`
- Evaluation: 5-fold stratified cross-validation

| Majority baseline accuracy | 0.538600 |
| CV accuracy mean | 0.644800 |

## Main Results

The model exceeded the majority-class baseline by 0.106200 local CV accuracy on
the larger synthetic fixture.

Compared with exp-002, CV accuracy was lower by 0.021867. Because both datasets
are generated fixtures with different seeds and sizes, this should be read as a
workflow comparison rather than a model-quality conclusion.

The submission file has 1200 rows and the columns `PassengerId` and
`Transported`, matching the expected Kaggle submission shape.

## Failures And Negative Results

- Official Kaggle data was not available, so this fixture cannot validate public
  leaderboard score.
- The fixture generator emitted pandas FutureWarnings when inserting missing
  values into bool-like columns.
- Larger fixture size did not improve CV accuracy relative to exp-002.

## Reproduction

Generate fixture data:

```bash
uv run python make_fixture_data.py --out-dir data --train-rows 5000 --test-rows 1200 --seed 99
```

Run baseline:

```bash
uv run python train_baseline.py --data-dir data --folds 5
```
