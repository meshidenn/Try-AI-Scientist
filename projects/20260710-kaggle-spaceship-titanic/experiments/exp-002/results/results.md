# Results

## Summary

Status: completed.

The local Spaceship Titanic-shaped fixture baseline completed. This validates
that the experiment workspace can generate data, train a model, produce local
cross-validation metrics, and write a Kaggle-shaped submission file.

This result does not measure Kaggle leaderboard performance because the dataset
is synthetic.

## Setup

- Experiment: `exp-002`
- Data: synthetic fixture generated by `workspace/make_fixture_data.py`
- Train rows: 1200
- Test rows: 400
- Model: `RandomForestClassifier`
- Evaluation: 5-fold stratified cross-validation

## Metrics

| Metric | Value |
| --- | ---: |
| Majority baseline accuracy | 0.533333 |
| CV accuracy mean | 0.666667 |
| CV accuracy std | 0.019543 |
| Fold count | 5 |
| Train accuracy | 0.786667 |

## Main Results

The model exceeded the majority-class baseline by 0.133333 local CV accuracy on
the synthetic fixture.

The submission file has 400 rows and the columns `PassengerId` and
`Transported`, matching the expected Kaggle submission shape.

No figures were generated.

## Failures And Negative Results

- Official Kaggle data was not available, so this fixture cannot validate public
  leaderboard score.
- The fixture generator emitted pandas FutureWarnings when inserting missing
  values into bool-like columns.

## Reproduction

Generate fixture data:

```bash
uv run python make_fixture_data.py --out-dir data --train-rows 1200 --test-rows 400 --seed 42
```

Run baseline:

```bash
uv run python train_baseline.py --data-dir data --folds 5
```
