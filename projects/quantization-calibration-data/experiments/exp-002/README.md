# exp-002

## Purpose

Run an LLM NVFP4 W4A4 calibration-domain sensitivity pilot. The experiment varies calibration data domain while holding the model and quantization recipe fixed.

## Pilot Scope

- Model: `Qwen/Qwen3-4B-Instruct-2507`
- Quantization: LLM Compressor `oneshot` with `QuantizationModifier(targets="Linear", scheme="NVFP4", ignore=["lm_head"])`
- Calibration domains: `general_chat`, `code`, `math_reasoning`
- Pilot sample count: 20 samples per domain
- Max sequence length: 2048
- Evaluation: held-out synthetic NLL/perplexity, 12 samples per domain, `max_length=512`

## Calibration Dataset

The current pilot uses synthetic prompt JSONL files generated by `workspace/build_calibration_sets.py`. These files are for pipeline validation only and are not final evidence for real calibration-domain effects.

| domain | file | samples | dataset/source | content style |
| --- | --- | ---: | --- | --- |
| `general_chat` | `artifacts/calibration/general_chat.jsonl` | 20 | Synthetic prompts in `build_calibration_sets.py` | Japanese/English daily chat, short QA, advice |
| `code` | `artifacts/calibration/code.jsonl` | 20 | Synthetic prompts in `build_calibration_sets.py` | Python, JavaScript, SQL, bug fixing, programming completion |
| `math_reasoning` | `artifacts/calibration/math_reasoning.jsonl` | 20 | Synthetic prompts in `build_calibration_sets.py` | Arithmetic, algebra, probability, short proof prompts |
| `mixed_balanced` | `artifacts/calibration/mixed_balanced.jsonl` | 18 | Generated mix from pilot domains | Balanced pilot mixture |

Planned real calibration datasets for the full experiment:

| domain | candidate dataset | reason |
| --- | --- | --- |
| `general_chat` | `HuggingFaceH4/ultrachat_200k` | Matches the Red Hat Qwen3 NVFP4 reference recipe. |
| `code` | MBPP/HumanEval prompts or permissive code-instruction corpus | Tests code-calibration effects. |
| `math_reasoning` | GSM8K train or similar math corpus | Tests reasoning-calibration effects. |
| `long_documents` | Long-document QA/RAG corpus | Tests long-context activation behavior. |
| `multilingual` | Japanese/English mixed instruction and translation corpus | Tests multilingual calibration effects. |

## Evaluation Dataset

The pilot evaluation uses synthetic held-out JSONL files generated by `workspace/build_evaluation_sets.py`. These are separate from the calibration files.

| domain | file | samples | note |
| --- | --- | ---: | --- |
| `general_chat` | `artifacts/evaluation/general_chat.jsonl` | 12 | Japanese/English chat and instruction responses |
| `code` | `artifacts/evaluation/code.jsonl` | 12 | small programming explanations and code snippets |
| `math_reasoning` | `artifacts/evaluation/math_reasoning.jsonl` | 12 | simple arithmetic and reasoning solutions |

## Current Pilot Result

The NVFP4 quantization pipeline completed for all three calibration domains, and NLL evaluation completed for the base model plus the three quantized variants.

Matched calibration did not win in this tiny synthetic pilot. The result should be treated as smoke-test evidence only; real corpora and task metrics are still needed.
