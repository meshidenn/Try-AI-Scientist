# Survey update: Spark-to-Paper

## 追加資料

- [Spark-to-Paper: End-to-End Research Paper Generation as a Composable Skill](https://arxiv.org/abs/2608.11924)
- Authors: Zhuoyang Qian, Biao Wu, Yiran Wang, Chris D. Yan, Desan Dai, Liangwei Zheng, Jin Jiang, Jusheng Zhang, Wenhao Wang
- arXiv:2608.11924v1、2026-08-12、アクセス日 2026-08-17

## 要点

Spark-to-Paper は、独立した研究エージェント基盤ではなく、既存 coding assistant 内で13個の composable skill を実行する end-to-end research paper generation system を提案する。文献検索、計画、執筆、実験、図、review を project artifact で接続し、実験計画と結果報告を分離する。さらに、deterministic integrity check、claim revision、Self-Refutation Loop の制御、editable vector figure の生成を扱う。

## 本 project への示唆

本 project の `project.yaml`、`survey/`、`spec.yaml`、`paper/`、`review/` の責務分離と整合する。検索研究の手法比較には用いず、研究workflow、artifact連携、実験結果に基づくclaim更新の関連研究として引用する。
